# Privacy and data notes

Last updated: July 28, 2026

StarNet Etsy Research is an early personal prototype. It has one user and no public account or signup system.

## Current state

The Etsy API connection is not active yet. The API application is pending personal approval, so the project does not currently retrieve or store Etsy API responses.

## Planned handling

When access is approved, the initial workflow will read only the public listing information needed for a specific comparison. I will document the exact Etsy API resources and OAuth scopes here after the connection is tested.

The project will not ask other Etsy sellers to connect their accounts. It will not collect customer payment information, messages, shipping addresses, or private seller records as part of the initial research workflow.

## Credentials

API keys and authorization tokens are stored outside the public repository. They are not included in source files, commits, screenshots, or this website.

## Research notes

The purpose of the tool is to help me write my own notes about broad market patterns. Those notes may cover things such as price ranges, product categories, personalization choices, and listing structure. They are for my own product-planning work.

## Changes

This document will be updated when the API connection is working and the final data fields, storage location, and retention rule have been tested. The repository's commit history will show those changes.
