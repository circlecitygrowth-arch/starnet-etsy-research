Personal project

StarNet Etsy Research

I'm building this small internal tool while I plan an Etsy shop. I wanted one place to compare public listing details, write down what I notice, and decide which original product ideas are worth testing.

Current status: early prototype

My Etsy API key request is under review. The public repository currently holds this project page and documentation; the API research workflow will be connected and tested after access is approved.

Why I started it

I was collecting product notes across browser tabs and loose documents, which got messy fast. This project is meant to make that routine more consistent: choose one category, compare the same public fields, keep my own notes, and then make a decision.

It is for my own use. There is no public signup, no customer account system, and I am not offering it to other Etsy sellers.

Planned research routine

  1. Choose one product phrase or category I want to study.
  2. Retrieve the public listing fields Etsy permits through the Open API.
  3. Compare practical details such as price, category, personalization choices, and listing structure.
  4. Write my own notes and decide whether to prototype an original product.

The purpose is comparison and note-taking. It is not a listing copier, bulk downloader, or resale service.

What stays human

I choose what to research, review the results, write the notes, and approve every product decision. Automation may help organize public information, but it does not decide what I sell or publish listings on its own.

Boundaries

I do not use this project to copy listing text, download products, or reproduce another seller's artwork, photos, files, branding, or designs. Any products, images, descriptions, and branding for my shop will be made separately as original work.

API credentials and authorization tokens are never committed to GitHub or displayed on this website. More detail is in the project's privacy notes.
